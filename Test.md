*Jawaabaha Quizkan waa inoo muhiim*
Amarada Terminal-ka
cd
Waxaad ku galeysaa folder
Tusaale: cd Documents → waxaad gashay folder-ka Documents

cd .. 
Waxaad ku laabaneysaa folderkii hore
Hal level ayaad dib ugu noqoneysaa

mkdir

Waxaad ku sameyneysaa folder cusub
Tusaale: mkdir project

ls
Waxaad ku arkeysaa waxa ku jira folder-ka
Files iyo folders dhan ayuu ku tusaa

Amarada Git

git init
Folder-ka ayuu ka dhigaa Git repository
-Waxaa la bilaabaa tracking (raacista isbeddelka files-ka)

repository
- Ma aha amar
- Waa magac macnihiisu yahay: meel lagu kaydiyo mashruuca (code-ka)

git clone
Wuxuu soo dejinayaa repository online ah
- Badanaa waxaa laga soo qaataa GitHub

git pull
Wuxuu soo qaataa updates cusub oo ka yimid server-ka
- Waxaad la socotaa wixii la beddelay

git add .
Wuxuu diyaarinayaa files-ka commit
- Dhammaan changes ayuu ku darayaa

git commit -m "text"
Wuxuu keydinayaa changes-ka
- "text" waa fariin sharaxeysa waxa aad bedeshay

git status
Wuxuu kuu sheegaa:
- wax cusub
- wax la beddelay
- wax diyaar u ah commit

git push
Wuxuu u diraa changes-ka GitHub
- Mashruuca online ayuu ku cusboonaysiiyaa

Si fudud u xasuuso (3 tallaabo muhiim ah)

Markaad wax bedesho:

git add . → diyaari
git commit -m "msg" → keydi
git push → dir online
